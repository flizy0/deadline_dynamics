01

ОПИСАНИЕ ДАННЫХ

Абсолютная частота

Формула
fᵢ = число наблюдений в категории i
Используется для

Число наблюдений в категории i.

Относительная частота

Формула
ri = fi / N
Используется для

Доля категории от общего числа наблюдений.

Процентная частота

Формула
percentagei = (fi / N) × 100%
Используется для

Доля категории, выраженная в процентах.

Мода

Формула
Мода = категория с наибольшей частотой
Используется для

Категория с наибольшей частотой.

02

СРАВНЕНИЕ

Наблюдаемая доля сдачи вовремя

Формула
p̂ = Non time / (Non time + Nlate)
Используется для

Оценка p по заданиям с известным исходом.

Разность в процентных пунктах

Формула
Δpp = p̂1 − p̂2
Используется для

Сравнение двух долей в процентных пунктах, а не в процентах изменения.

03

ВЕРОЯТНОСТНАЯ МОДЕЛЬ

Сочетания

Формула
C(n,k) = n! / (k!(n−k)!)
Используется для

Число способов выбрать k успехов из n испытаний.

Биномиальная вероятность

Формула
P(X = k) = C(n,k)pk(1−p)n−k
Используется для

Вероятность ровно k успехов в n независимых испытаниях.

Математическое ожидание

Формула
E[X] = np
Используется для

Среднее число успехов в группе размера n.

Дисперсия

Формула
Var(X) = np(1−p)
Используется для

Мера разброса числа успехов относительно ожидания.

Стандартное отклонение

Формула
σ = √(np(1−p))
Используется для

Типичный масштаб отклонения числа успехов.

Хвостовая вероятность

Формула
P(X ≥ k) = Σx=kn C(n,x)px(1−p)n−x
Используется для

Вероятность получить не менее k успехов.

04

СИМУЛЯЦИЯ

Эмпирическая вероятность

Формула
p̂_sim = успешные симуляции / все симуляции
Используется для

Доля успешных симуляций среди всех повторений.

Ошибка симуляции

Формула
Error = |ptheory − psimulation|
Используется для

Абсолютное расхождение теоретической и эмпирической вероятностей.

05

ГРУППИРОВКА ЧИСЛОВЫХ ДАННЫХ

Размах

Формула
R = Max − Min
Используется для

Разность максимального и минимального значений.

Правило Стерджесса

Формула
K = 1 + 3.322 log10(N)
Используется для

Приближённое число интервалов для группировки числовых данных.

Ширина класса

Формула
C ≈ R / K
Используется для

Приблизительная ширина одного интервала.

Применяется к числовым результатам симуляции, а не к категориальным ответам анкеты.

ОДИН ПРИМЕР

Пример на текущих данных

Вовремя17
С опозданием6
Известные исходы23

p̂ = 17 / 23

p̂ ≈ 0.739 ≈ 73.9%

Ограничения

  • Наблюдаемая связь не доказывает причинность.
  • Добровольная неслучайная выборка не представляет всех студентов.
  • Некоторые группы малы; сравнения описывают только эти ответы.
